# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi latihan mata kuliah Pemrograman Mobile yang dibangun dengan Flutter. Proyek ini
merupakan titik awal yang akan dikembangkan sepanjang perkuliahan.

## Tujuan
Mempraktikkan dasar pengembangan aplikasi mobile dengan Flutter, meliputi struktur proyek,
widget, navigasi antar halaman, dan pengelolaan state, sebagai bekal untuk membangun
aplikasi yang lebih kompleks.

## Rencana Fitur
1. Halaman utama yang memperkenalkan proyek dan pengembang.
2. Navigasi antar halaman, dari halaman utama ke halaman detail.
3. Formulir input sederhana dengan penyimpanan data lokal.

Ketiga fitur direncanakan ditambahkan secara bertahap mengikuti materi perkuliahan.

## Cara Menjalankan
Pastikan Flutter SDK terpasang. Dari folder akar proyek (folder yang berisi `pubspec.yaml`),
jalankan:

```
flutter pub get
flutter run
```

`flutter pub get` telah diverifikasi berhasil pada lingkungan pengembangan (10 September
2026). Saat `flutter run` diminta, pilih perangkat tujuan (Windows, Chrome, atau emulator)
yang tersedia.
